# AUEB Coding Factory - C# .NET Core

C# .NET Core learning material, code examples, and coding challenges from the Coding Factory program at AUEB.

_C# 14 · .NET 10_

## Course Structure & Projects

### 1. C# .NET Core Introduction & Primitive Data Types

Introduces C# syntax, basic console output, variable declarations, and primitive types.

`BillCalcApp` • `DataTypes` • `HelloWorld` • `KilometersApp` • `NumberRead` • `PrintingApp` • `ProductsVat` • `RenterCarApp` • `SalaryCalcApp` • `TravelingApp`

### 2. Control Structures, Methods, Reference Types & RegEx

Covers conditional logic, loops, array manipulations, reusable methods, and regular expressions.

`ArraysApp` • `CitiesForApp` • `DoWhileApp` • `ExtractCapitals` • `FibonacciIterative` • `FormatExceptionApp` • `IfUseCases` • `LinqArrays` • `NullableStringApp` • `PointApp` • `PositivesCount` • `PowerApp` • `ProductWhileApp` • `PyramidChallenge` • `RegExApp` • `StringsApp` • `SwapApp` • `SwitchApp` • `WhileApp`

### 3. OOP, Inheritance, Interfaces, Abstract Classes, Collections & LINQ

Focuses on Object-Oriented Programming concepts, class hierarchies, interface contracts, collection types, and LINQ queries.

`CollectionsApp` • `InterfacesApp` • `LinqApp` • `OOApp` • `OperatorOverloading` • `UtilityClassesApp`

### 4. Exceptions, Dynamic Data Structures & File I/O

Explores exception handling, stack data structures, and reading/writing data streams to files.

`FileManagementApp` • `StackApp` • `StreamReadWrite`

### 5. ASP .NET Core Introduction & Razor Pages

Introduction to Web Development using ASP.NET Core framework and Razor Pages architecture.

`WebAppStarter10`
